# Google Drive 远程挂载 - 飞牛NAS应用

一个用于扩展飞牛NAS远程挂载模块的fpk应用，支持将Google Drive挂载到飞牛文件管理器中使用。

## 功能特性

- ✅ **原生集成** - 直接在飞牛远程挂载模块中显示Google Drive
- ✅ **实时容量显示** - 实时显示Google Drive存储空间使用情况
- ✅ **代理支持** - 支持HTTP/SOCKS5代理，适合中国大陆用户
- ✅ **自动挂载** - 系统启动时自动挂载Google Drive
- ✅ **稳定可靠** - 基于rclone的成熟挂载方案

## 系统要求

- 飞牛NAS系统版本：1.0.0+
- rclone：需要在应用中心安装
- Node.js：18.0.0+（应用中心安装）
- 网络连接：需要互联网访问（可通过代理）

## 安装方法

### 1. 安装前置依赖

在飞牛应用中心安装：
- **rclone** - 云存储管理工具
- **Node.js** - JavaScript运行时

### 2. 安装本应用

1. 下载 `fn-google-drive.fpk` 文件
2. 打开飞牛NAS管理界面
3. 进入"应用中心"
4. 点击左下角"手动安装"
5. 选择下载的fpk文件
6. 点击"安装"

## 使用方法

### 1. 配置 Google Drive

1. 打开应用（桌面图标或应用中心）
2. 切换到"配置 Google Drive"标签
3. 粘贴您的 rclone 配置文件内容
4. 点击"保存配置"

**获取rclone配置文件的方法：**

在本地电脑上运行：
```bash
# 安装rclone
# Windows: https://rclone.org/downloads/
# macOS: brew install rclone
# Linux: curl https://rclone.org/install.sh | sudo bash

# 配置Google Drive
rclone config
# 按提示选择 Google Drive，完成授权

# 查看配置文件
cat ~/.config/rclone/rclone.conf
```

### 2. 配置代理（可选）

如果您在中国大陆：

1. 切换到"代理设置"标签
2. 勾选"启用代理"
3. 选择代理类型（HTTP或SOCKS5）
4. 填写代理地址和端口
5. 点击"保存代理配置"
6. 点击"测试连接"验证代理是否可用

### 3. 启动挂载

1. 点击"启动挂载"按钮
2. 等待挂载完成
3. 在飞牛文件管理器的"远程挂载"中找到 Google Drive

### 4. 访问文件

挂载成功后，您可以：
- 在飞牛文件管理器中浏览Google Drive文件
- 像使用本地文件一样复制、移动、删除文件
- 在飞牛影视、相册等应用中使用挂载的文件
- 通过Docker容器访问挂载的文件

## 容量监控

应用会实时显示Google Drive的存储空间使用情况：
- 已用空间
- 可用空间
- 回收站占用
- 使用百分比

点击"刷新"按钮可以立即更新容量信息。

## 配置文件位置

- **rclone配置**: `/tmp/fn-google-drive/config/rclone.conf`
- **代理配置**: `/tmp/fn-google-drive/config/proxy.json`
- **挂载点**: `/vol1/GoogleDrive`
- **日志文件**: `/tmp/fn-google-drive/config/mount.log`

## 常见问题

### Q: 为什么需要rclone？

A: rclone是一个开源的云存储管理工具，支持70+种云存储服务。本应用使用rclone来连接和挂载Google Drive。

### Q: 如何获取Google Drive的client_id和client_secret？

A: 您需要在Google Cloud Console创建OAuth 2.0凭据：
1. 访问 https://console.cloud.google.com
2. 创建项目并启用Google Drive API
3. 创建OAuth 2.0客户端ID
4. 获取client_id和client_secret

### Q: 挂载后文件访问速度慢怎么办？

A: 可以尝试：
1. 配置代理优化网络连接
2. 使用rclone的缓存功能
3. 检查网络带宽

### Q: 如何设置开机自动挂载？

A: 应用安装后会自动配置开机启动。如果需要手动配置，可以将启动命令添加到系统启动脚本中。

### Q: 挂载后飞牛影视无法扫描文件？

A: 飞牛影视对远程挂载的文件采用"弱扫描"策略，需要手动进入目录才会触发扫描。这是为了规避网盘风控的设计。
